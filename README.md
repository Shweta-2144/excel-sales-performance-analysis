# Sales Performance Analysis using Excel

## Project Description
This project analyzes sales executive performance using Microsoft Excel.
It includes Pivot Tables, formulas, KPIs, and an interactive dashboard to
track sales targets and regional performance.

## Skills Used
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Conditional Formatting
- Dashboard Creation

## How to Use
1. Download the Excel file
2. Open it in Microsoft Excel
3. Enable editing and macros if prompted
4. Explore the Pivot Tables and Dashboard sheets
